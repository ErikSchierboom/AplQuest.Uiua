# AplQuest.Uiua

A translation of the [APL quest](https://github.com/Dyalog/apl.quest) exercises to [Uiua](https://www.uiua.org/).

## Website

The website can be found at: https://erikschierboom.github.io/AplQuest.Uiua/

## Attribution

The problems and tests are adapted from [APL Quest](https://apl.quest)([Dyalog/apl.quest](https://github.com/Dyalog/apl.quest)), a collection of phase 1 problems from the 2013–2023 APL Problem Solving Competition rounds, licensed under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
The Uiua solutions, the [website](web/) generator, and this repository's other original
content are not affiliated with or endorsed by Dyalog.

## Usage

The [web/](web/dist) directory contains a static website, generated from this repository's exercises, where each problem can be solved in Uiua directly in the browser and checked against its own tests.
See [web/README.md](web/README.md) for how to build and serve it.
